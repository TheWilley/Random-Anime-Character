# Random Anime Character

Very simple web app to get a random anime character. The dataset (characters the app choose from) is derived
from [MyAnimeList's top 500 most favorited characters](https://myanimelist.net/character.php) as of 2026/07/26.

## How to use

Simply go to the [official webpage](https://thewilley.github.io/random-anime-character/) to get
started, or run the app yourself by following these steps:

```bash
# Clone this repository
$ git clone https://github.com/TheWilley/random-anime-character.git

# Go into the repository
$ cd random-anime-character

# Install dependencies
$ npm install

# Build app
$ npm run build

# If you want to start the app
$ npm run preview

# If you want to develop the app
$ npm run dev
```
